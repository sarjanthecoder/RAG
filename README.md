🤖 ResumeAI – RAG-Powered Resume Chatbot

ResumeAI is an intelligent chatbot that answers questions about your resume using Retrieval-Augmented Generation (RAG), powered by Google Gemini AI.
Upload your resume as a PDF and chat with it in real time.

✨ Features

📄 PDF Upload – Drag & drop your resume (PDF format)

🧠 RAG Architecture – Context-aware answers based on your actual resume

⚡ Instant Responses – Fast and accurate AI replies

🎨 Modern UI – Clean glassmorphism design

🔒 Privacy-First – Resume data stays local (no database storage)

🛠️ Tech Stack
Backend

Python 3.10+

FastAPI

Google Gemini AI

PyPDF

Frontend

React.js

Vite

CSS3 (Glassmorphism UI)

🚀 Getting Started
Prerequisites

Python 3.10 or above

Node.js 18 or above

Google Gemini API Key

Installation
1️⃣ Clone the repository
git clone https://github.com/sarjanthecoder/resume-ai-chatbot.git
cd resume-ai-chatbot

2️⃣ Backend setup
cd backend
pip install -r requirements.txt
cp .env.example .env


Edit .env and add your Google Gemini API key:

GOOGLE_API_KEY=your_api_key_here

3️⃣ Frontend setup
cd frontend
npm install

▶️ Running the Application
Start the backend server
cd backend
python main.py

Start the frontend
cd frontend
npm run dev

Open in browser
http://localhost:5173
